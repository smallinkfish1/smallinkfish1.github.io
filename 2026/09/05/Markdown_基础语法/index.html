1. 标题语法 Heading Syntax

用于区分文章层级，共支持 1–6 级标题。 Used for article hierarchy, supports level 1 to 6.

规则：# 与文字之间必须有空格 Rule: Always add a space after #

2. 段落与换行 Paragraph & Line Break

普通文字直接书写即为段落。 Plain text forms a paragraph directly.

  • 换行（软换行）：行尾两个空格 + 回车 Soft line break: two spaces + enter

  • 换段（新段落）：直接空一行 New paragraph: leave one blank line

博客使用小贴士 Blog Tips（中英双语）

中文

  1. 所有博客文章必须放在 content/posts/ 目录

  2. draft: true 为草稿，线上不会显示，发布务必改为 false

  3. 所有语法 Hugo + PaperMod 完全兼容

  4. 文件名建议英文小写、不含空格

English

  1. All posts should be placed in content/posts/

  2. Set draft: false before publishing

  3. All syntax is fully compatible with Hugo & PaperMod

  4. Use lowercase English filenames without spaces
