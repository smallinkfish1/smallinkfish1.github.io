一、主板芯片组全系列知识

主板芯片组决定了CPU 能否超频、能插多少设备、能跑多少带宽。一句话总结：

芯片组决定平台上限，CPU 决定平台实际性能。

1. Intel 主板系列定位与差异

1.1 系列定位总览

系列 代表型号 核心特性 目标用户
入门级 H110 / H310 / H410 / H510 / H610 无超频、供电基础、拓展最少 家用办公
中端主流 B150 / B250 / B360 / B460 / B560 / B660 / B760 均衡拓展、性价比主力 游戏玩家、全能用户
高端消费 H170 / H270 / H370 / H470 / H570 / H670 / H770 多接口、多通道、拓展丰富 高端玩家、创作者
旗舰超频 Z170 / Z270 / Z370 / Z390 / Z490 / Z590 / Z690 / Z790 支持 CPU 超频、满血拓展 超频玩家、发烧友
商用政企 Q170 / Q270 / Q370 / Q470 / Q570 / Q670 支持 vPro、AMT 远程管理 企业、机房
至尊/工作站 X299（X 系列）、W 系列 多通道内存、ECC 支持 专业工作站

1.2 关键点解读

  • H 系列：供电规格通常只够带 65W 级别非 K CPU，内存插槽多为 2 条，M.2 接口 1~2 个。适合 i3 / i5 非 K + 单显卡 的省心配置。
  • B 系列：千元价位主板销量之王。内存插槽 4 条、M.2 接口 2~3 个、PCIe 插槽齐全。B560 开始开放内存超频，B660 起支持 PCIe 5.0 显卡槽，B760 在供电上进一步加码，可带动 i7-14700K 级别 CPU。
  • H 系列（高端）：存在于 300~700 系中，例如 H770。接口数量介于 B 与 Z 之间，不支持 CPU 超频，定位略尴尬，实际销量远小于 B/Z。
  • Z 系列：唯一支持倍频超频的消费芯片组，配合 K/KF 系列 CPU 使用。同时提供最多 USB 接口、最高内存频率支持、PCIe 通道拆分（如 x16 拆成 x8+x8 双显卡）。
  • Q 系列：带 Intel vPro 技术和 AMT 远程管理（可远程开机、重装系统），个人用户用不上，政企采购专属。
  • X / W 系列：X299 支持 LGA2066 的酷睿 X（如 i9-10980XE）；W 系列（如 W680）支持 ECC 内存和 Xeon W 系列 CPU，属于专业工作站平台。

1.3 常见误区提醒

  • H 开头既可能是入门级 H610，也可能是高端消费 H770，要看具体数字：三位数系列中，第一个数字代表代数（6xx = 600 系，12~14 代酷睿平台）。
  • 芯片组本身不产生性能差距：同一颗 CPU 在 B760 和 Z790 上，不超频时跑分差距通常在误差范围内。差距在拓展性与供电上限。

2. AMD 主板系列定位与差异

2.1 系列定位总览

系列 代表型号 核心特性 目标用户
入门级 A320 / A520 / A620 基础拓展、无 PCIe 4.0（A320）或有限 办公、亮机
中端主流 B350 / B450 / B550 / B650 / B850 全能甜品、超频支持 游戏玩家
旗舰消费 X370 / X470 / X570 / X670 / X670E / X870E 满血 PCIe 5.0、多设备拓展 发烧友、创作者
商用/至尊 PRO 系列、TRX40/TRX50（线程撕裂者）、WRX80/WRX90 多通道内存、ECC、海量 PCIe 工作站、HEDT

2.2 关键点解读

  • AMD 平台一大福利：从 B350 开始，几乎所有 B/X 芯片组都支持 CPU 超频，这一点比 Intel 良心得多。A 系列除外（A320/A520/A620 不支持超频）。
  • A520 vs B550：A520 不支持 PCIe 4.0、不支持超频，但可搭载锐龙 5000 系，是极致性价比办公首选；B550 则提供 PCIe 4.0 显卡槽 + 一个 PCIe 4.0 M.2 口，是 AM4 平台性价比之王。
  • B650 / B850（AM5 平台）：B650 支持 DDR5 + PCIe 5.0 M.2（部分型号）；B850 为 800 系中端，显卡槽强制 PCIe 5.0。带 E 后缀的型号（如 B650E）表示显卡槽也为 PCIe 5.0。
  • X670E / X870E：双芯设计，满血 PCIe 5.0 通道拆分，适合多显卡、多 SSD、万兆网卡等重度拓展。
  • TRX / WRX 系列：线程撕裂者平台，四通道/八通道内存、128 条 PCIe 通道，价格过万，属专业生产力领域。

2.3 AM4 与 AM5 平台对比

对比项 AM4（A320~X570） AM5（A620~X870E）
CPU 接口 PGA 1331 针 LGA 1718 触点
内存支持 DDR4 仅 DDR5
最长服役周期 2016~2022（7 年 5 代） 官方承诺支持至 2027+
二手性价比 极高 中等（尚在新周期）

3.1 同代芯片组性能层级排序（从高到低）

3.2 CPU / 显卡 / 硬盘通道适配原则

  • 供电匹配：入门级主板（H610/A620）建议搭配 65W 级别 CPU；带 K 的 CPU 建议 B760/B650 起步，i7/i9 K 系列建议供电更强的型号。
  • PCIe 通道匹配：RTX 4060 及以下显卡用 PCIe 4.0 通道即可；RTX 4070 Ti / RX 7800 XT 以上建议确认主板显卡槽为 PCIe 4.0 x16 及以上。
  • M.2 数量规划：1 根系统盘起步，游戏玩家建议主板至少 2 个 M.2 口；素材库大、做剪辑建议 3 个以上或考虑 PCIe 转接卡。

3.3 按场景推荐

场景 推荐搭配
家用办公 i3-12100/13100 + H610，或 R5 5600G + A520/B450
游戏甜品 i5-12400F/13400F/14600KF + B760M，或 R5 7500F + B650M
高端游戏 i7-14700KF + Z790/B760 重炮手，或 R7 7800X3D + B650M/X670
生产力创作 i9-14900K + Z790，或 R9 7950X + X670E
极致性价比老平台 R5 5600 + B550M（AM4 二手平台）

2. 架构迭代与性能发展

2.1 6~9 代酷睿（LGA1151）：经典老平台

  • 架构：Skylake（6 代）→ Kaby Lake（7 代）→ Coffee Lake（8/9 代）
  • 特点：4~8 核时代，IPC 每代提升约 5%。i7-8700K（6C12T）是当年游戏神 U。
  • 现状（2026 年）：DDR4 + 老接口，仅建议二手千元机捡垃圾，不建议新装。

2.2 10~11 代酷睿（LGA1200）：普及过渡平台

  • 架构：Comet Lake（10 代）→ Rocket Lake（11 代，反向升级）
  • 特点：10 代 i5 升至 6 核（10400F 曾是性价比之王）；11 代全面支持 PCIe 4.0 但核心数缩水，生命周期仅一年。
  • 现状：10 代二手尚可，11 代完全不推荐。

2.3 12~14 代酷睿（LGA1700）：大小核革命

  • 架构：Alder Lake（12 代，首次引入 P+E 大小核）→ Raptor Lake（13/14 代，堆更多 E 核）
  • 性能跨越：i5-12600K 多核反超上一代 i9-11900K，单核游戏性能领先锐龙 5000 系，结束了 AMD 长达两年的游戏性能统治。
  • 注意：13/14 代高功耗型号（i7/i9 K）需注意主板供电与散热，14700K 满载功耗可超 250W。

延伸说明：Intel 在 2024 年底推出了酷睿 Ultra 200 系列（Arrow Lake，LGA1851 新接口，取消超线程），命名改为”酷睿 Ultra 5/7/9”，标志着”酷睿 i”时代落幕。本文大纲以 12~14 代为经典 i 系列主线，新平台用户可将”酷睿 Ultra 7 265K”大致对标” i7-14700K 的继任者”来理解。

3. 各代 CPU 性能横向对比

3.1 单核 / 多核 / 游戏 / 生产力差距总结

以 Cinebench R23 多核跑分为参照量级（近似值，非精确值）：

CPU 多核（约） 单核（约） 游戏表现
i7-8700K（9 代） ~10000 ~1350 尚能 1080P 中高画质
i5-10400F（10 代） ~9000 ~1250 网游够用
i5-12400F（12 代） ~12000 ~1650 2K 甜品
i5-13600KF（13 代） ~24000 ~2000 全面超越 12 代 i7
i9-14900K（14 代） ~56000 ~2200 游戏顶级，但被 X3D 压制

结论： - 跨 3 代 ≈ 性能翻倍：10 代 i5 → 13 代 i5 多核提升约 150%。 - 12 代是分水岭：12 代以前全线不推荐新装；12 代起每一代都可战。 - 游戏看单核 + 缓存：14900K 游戏性能仍不敌 R7 7800X3D（AMD 3D V-Cache 缓存技术优势）。

3.2 新旧旗舰跨代碾压关系

上一代 i7 约等于下一代 i5：i7-12700K ≈ i5-13600KF（多核打平甚至小输）。

4. Intel CPU 最佳选购方案

4.1 办公性价比选型

  • i3-12100（带核显）+ H610：整机 1500 元级别搞定办公，UHD 730 核显可硬解 4K 视频。

4.2 游戏甜品选型

  • i5-12400F / 13400F + B760M + DDR4：2K 分辨率带 RTX 4060 Ti / 4070 无压力。
  • i5-14600KF + B760M 重炮手：预算充足者的游戏毕业款。

4.3 高端旗舰生产力选型

  • i7-14700KF（20 核 28 线程）+ Z790：剪辑、渲染、虚拟机多开全能。
  • i9-14900K + Z790 旗舰板 + 360 水冷：仅适合明确需要顶级多核的用户，普通游戏玩家不必上 i9。

2. 架构迭代与性能发展

2.1 Zen1 / Zen2：初代崛起（2017~2019）

  • Zen1（1000 系）：8 核 16 线程把 Intel 主流平台从 4 核时代直接拖到 8 核时代，但单核偏弱。
  • Zen2（3000 系）：7nm 工艺 + 大缓存设计，R5 3600 成为史上销量最高的 CPU 之一，多核性价比首次反超 Intel。

2.2 Zen3：游戏性能巅峰（2020~2022）

  • R5 5600 / 5600X / 5800X3D：Zen3 的 CCX 整合设计大幅降低延迟，游戏性能首次反超同期 Intel（11 代）。
  • 5800X3D（2022）和 5700X3D（2024）凭借 96MB 三级缓存，游戏帧数越级打平甚至超过 i9-12900K，被誉为”保值神 U”。

2.3 Zen4 / Zen5：新一代全能平台（2022 至今）

  • Zen4（7000 系，AM5 + DDR5）：R5 7600、R7 7800X3D、R9 7950X。能效比大幅改善，但 AM5 平台初期成本偏高。
  • Zen5（9000 系）：IPC 提升约 16%，9800X3D 成为地表最强游戏 CPU，游戏与生产力双冠；9950X 在多核生产力上压制 14900K 且功耗更低。

参数 DDR3 DDR4 DDR5

DDR5 关键理解：虽然时序数字（CL40）比 DDR4（CL16）难看，但频率翻倍后实际延迟（ns 计算）并未恶化；且单条即相当于”内部双通道”，小容量单条不再像 DDR4 时代那样严重损失核显性能。

2. 频率、时序、容量性能差距

2.1 内存延迟计算公式（看懂时序的前提）

$$ \text{实际延迟（ns）} = \frac{\text{CL时序} \times 2000}{\text{频率（MT/s）}} $$

  • 例：DDR4-3200 CL16 的延迟为 $\frac{16 \times 2000}{3200} = 10\ \text{ns}$
  • 例：DDR5-6000 CL30 的延迟为 $\frac{30 \times 2000}{6000} = 10\ \text{ns}$（与 DDR4 打平，但带宽近乎翻倍）

内存带宽计算公式：

$$ \text{理论带宽（GB/s）} = \frac{\text{频率（MT/s）} \times 64\ \text{bit}}{8 \times 1000} $$

  • DDR4-3200 单通道：3200 × 64/8000 = 25.6 GB/s，双通道翻倍约 51.2 GB/s
  • DDR5-6000 单通道：48 GB/s，双通道约 96 GB/s

2.2 不同代际内存游戏帧数差异

平台 游戏帧数差距（1080P，搭配同级 CPU/显卡）
DDR4-2666 vs DDR4-3600 同平台换条提升 5~15%（尤其 X3D 之外、吃内存的 AMD 平台）
DDR4 vs DDR5（同代 CPU 可选平台） DDR5-6000 领先 5~10%，X3D 差距缩小到 2~5%
单通道 vs 双通道 核显差距可达 30~50%，独显也有 5~10% 损失——装机铁律：内存必须双通道！

2.3 多开、建模、AI 内存需求

  • 日常办公 / 网游：16G 起步
  • 2K 游戏 / 剪辑 / 虚拟机：32G 标配
  • 3D 建模 / 大型工程 / 本地大模型：64G 起步（跑 70B 量化模型建议 128G）
  • DDR5 新优势：单条 48G 普及，两条即可 96G，ITX 双槽主板也能上大容量

一线原厂 三星、海力士、镁光（英睿达） 自产颗粒，兼容性最强，超频一般
一线模组 金士顿（Fury 野兽/叛逆者）、芝奇（皇家戟/幻锋戟）、海盗船、威刚（XPG） 颗粒混用但筛选严格，RGB 与高频款丰富
二线性价比 光威（天策/神策）、阿斯加特、金百达（刃/黑爵）、宏碁掠夺者 长鑫/海力士颗粒，便宜大碗，注意买标明颗粒的型号
超频特化 影驰 HOF、十铨 XTREEM、芝奇 Trident Z 特挑颗粒，冲击 8000+ 频率

避坑要点： - 颗粒优先级：海力士 A-die / M-die > 长鑫颗粒 > 三星 B-die（DDR4 时代）> 其他 - 买 DDR5 认准 海力士 A-die 基本不翻车；DDR4 老平台认准 CJR/DJR 颗粒（金百达、科赋性价比款常用）。

4. 内存最佳搭配方案

4.1 老平台升级选型

  • DDR4 平台：补两条 8G 组双通道即可；新装 AM4 捡漏平台直接上 32G（16G×2）DDR4-3200，约 250 元，白菜价。

4.2 新平台游戏 / 生产力标配

  • 游戏标配：DDR5-6000 CL30/CL28 16G×2，海力士 A-die，约 500~700 元——AM5 与 Intel 平台的甜点频率
  • AMD 7000/9000 系注意：内存频率超过 6400 后 FCLK 分频，6000 左右是最优解，不要盲目追高
  • 生产力标配：DDR5-6400 32G×2（64G）起步；剪辑、虚拟机用户直接 96G（48G×2）

八、硬盘全系列知识（HDD / SSD 全接口）

1. 机械硬盘 HDD 分类

类型 转速 典型缓存 连续读写 适用场景
5400 转（蓝盘/监控盘） 5400 RPM 128~256M ~150 MB/s NAS、仓库盘、安静需求
7200 转（蓝盘/企业盘） 7200 RPM 256M 200250 MB/s 游戏仓库、日常资料
万转黑盘 / 企业级 10000+ RPM 512M+ 250300 MB/s 高性能仓库（已基本被 SSD 替代）

选购要点： - 垂直式（CMR）vs 叠瓦式（SMR）：一定买 CMR 垂直盘！SMR 叠瓦盘写入大文件时速度断崖下跌（掉速到 30MB/s），避坑型号如 WD 蓝盘 2T/4T（SMR）——认准”企业级、监控紫盘、NAS 红盘”系列基本都是 CMR。 - 冷备份场景：HDD 断电存放数据稳定性优于 SSD（SSD 断电久了会掉数据），重要资料仍以 HDD 或光盘备份。

2. 固态硬盘 SSD 全接口迭代

接口 协议/通道 理论上限 实际速度 定位
SATA 3.0 AHCI 600 MB/s 550 MB/s 老平台升级、仓库盘
M.2 NVMe PCIe 3.0 NVMe 4 GB/s ~3500 MB/s 老平台 M.2 口上限
M.2 NVMe PCIe 4.0 NVMe 8 GB/s ~7000 MB/s 当前主流标配
M.2 NVMe PCIe 5.0 NVMe 16 GB/s 1000014000 MB/s 旗舰极速盘（需散热片）

2.1 各档位详解

  • SATA SSD：2.5 寸，兼容所有带 SATA 口的电脑；速度已到接口天花板，胜在便宜稳定（1T 约 300 元）。
  • PCIe 3.0 SSD：如 SN570、致态 TiPlus5000，速度 3500 MB/s，日常体验与 4.0 差距极小（加载游戏差距 1~2 秒内）。
  • PCIe 4.0 SSD：如三星 990 Pro、致态 TiPro7000、西数 SN850X，7000 MB/s 满速盘，2026 年装新机的默认选择。
  • PCIe 5.0 SSD：如三星 9100 Pro、英睿达 T705，速度破万但发热巨大（必须配厚实散热马甲，部分主板自带风扇），日常体验提升有限，仅适合 8K 视频剪辑、超大文件搬运用户。

2.2 缓外速度概念

SSD 标注的 7000 MB/s 是”SLC 缓存内”速度，缓存写满后直写 TLC 颗粒的速度（缓外速度）才是真实下限：

$$ \text{拷贝超大文件实际时间} \approx \frac{\text{缓存容量}}{\text{缓内速度}} + \frac{\text{剩余容量}}{\text{缓外速度}} $$

  • 好的 TLC 盘缓外约 2000~4000 MB/s（如 990 Pro、致态 TiPlus7100）
  • 差的 QLC 盘缓外可能只有 100~300 MB/s（部分低端盘）——仓库盘也要避开杂牌 QLC。

3. 硬盘品牌系列性能与寿命差异

3.1 颗粒等级：原厂 > 白片 > 黑片

3.2 主流可靠型号梯队（2026）

梯队 代表型号 质保
旗舰原厂 三星 990 Pro、西数 SN850X、海力士 P41、英睿达 T500/T705 5 年
国产之光 致态（长江存储）TiPlus7100 / TiPro7000 / PC005 5 年，颗粒自产
性价比首选 铠侠 SD10/SE10、闪迪 SN580、金士顿 NV2（注意 QLC/TLC 混发） 3~5 年
大容量仓库 金百达 KP260/KP230 Plus（长江颗粒） 3 年，便宜大碗

TBW（总写入寿命）参考：1T 盘约 600 TBW、2T 约 1200 TBW——普通用户 10 年也写不完，不必过度焦虑寿命，优先避坑杂牌掉盘。

4. 硬盘最优组合方案

4.1 纯固态方案（推荐）

  • 预算型：1T PCIe 4.0 盘（系统+游戏全塞），约 350 元
  • 主流型：1T 系统/游戏 + 2T 仓库（双 M.2 口），约 900 元
  • 生产力型：2T 系统 + 4T 仓库 + NAS 冷备份

4.2 固态 + 机械混搭方案

  • 经典结构：512G~1T SSD（系统盘）+ 4T/8T HDD（仓库盘）
  • HDD 选型：NAS 红盘或企业盘（CMR），垂直记录保平安。

4.3 系统盘 / 游戏盘 / 资料盘合理分配

盘位 容量建议 用途 类型
系统盘 500G~1T 系统 + 软件 + 剪辑缓存 高速 TLC（带缓最好）
游戏盘 1T~2T Steam/Epic 库 TLC 即可，QLC 也能忍
资料盘 2T~4T+ 素材、照片、文档 大容量 SSD 或 HDD（CMR）
备份盘 ≥资料盘容量 重要数据冷备份 HDD + 定期通电，或云端双备份

铁律：无论几块盘，重要数据至少两份（本地 + 异地/云端）。SSD 坏了很难恢复数据，HDD 还能开盘抢救。

附录：硬件性能计算常用公式

1. CPU 性能估算

理论浮点性能（FLOPS）：

FLOPS = 核心数 × 频率（GHz） × 每周期浮点操作数（FMA = 2） × SIMD宽度

以 i5-13600KF 为例（6P+8E，P 核支持 AVX2，8 宽 FMA）：仅估算大核部分，6 × 5.1 × 2 × 16 ≈ 979 GFLOPS（仅供参考量级）。

2. 显卡性能估算

像素填充率：

像素填充率 = ROPs 数量 × 核心频率

显存带宽（决定高分辨率游戏下限）：

$$ \text{显存带宽（GB/s）} = \frac{\text{显存频率（MHz）} \times \text{位宽（bit）}}{8 \times 1000} $$

  • 例：RTX 4060（GDDR6 17 Gbps × 128bit）：17000 × 128/8000 = 272 GB/s（这就是它 2K 性能受限的主因）
  • 例：RX 7800 XT（19.5 Gbps × 256bit）：624 GB/s

3. 电源功率估算

$$ P_{\text{电源额定}} \geq \frac{P_{\text{CPU满载}} + P_{\text{显卡满载}} + 100\text{W（其他硬件）}}{0.8\ \text{（留 20\% 余量）}} $$

  • 例：i5-13400F（148W）+ RTX 4060 Ti（160W）：(148 + 160 + 100)/0.8 ≈ 510W → 选 550W~650W 金牌电源。
