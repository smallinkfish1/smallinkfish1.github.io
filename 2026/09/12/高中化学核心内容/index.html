高中化学核心内容知识手册

（涵盖无机、有机、反应原理三大模块，方程式全配平、考点全覆盖、高考规范版）

板块一：无机化学方程式大全（按元素分类）

1.1 钠及其化合物

单质钠

反应方程式 反应条件/现象 离子方程式
4Na + O2 = 2Na2O 常温，银白色变暗 4Na + O2 = 2Na2O
$2Na + O_2 \stackrel{\Delta}{=\!=\!=} Na_2O_2$ 加热，黄色火焰，生成淡黄色固体 ——
2Na + 2H2O = 2NaOH + H2↑ 浮、熔、游、响、红 2Na + 2H2O = 2Na+ + 2OH− + H2↑
2Na + 2HCl = 2NaCl + H2↑ 剧烈反应 2Na + 2H+ = 2Na+ + H2↑
2Na + 2CH3CH2OH = 2CH3CH2ONa + H2↑ 缓慢反应，钠沉在底部 ——
2Na + CuSO4 + 2H2O = Cu(OH)2 ↓ +Na2SO4 + H2↑ 钠先与水反应，再与盐反应 2Na + Cu2+ + 2H2O = Cu(OH)2 ↓ +2Na+ + H2↑

氧化钠与过氧化钠

反应方程式 反应条件/现象 离子方程式
Na2O + H2O = 2NaOH 白色固体溶解 Na2O + H2O = 2Na+ + 2OH−
Na2O + CO2 = Na2CO3 —— ——
2Na2O2 + 2H2O = 4NaOH + O2↑ 淡黄色固体，放出气体，放热 2Na2O2 + 2H2O = 4Na+ + 4OH− + O2↑
2Na2O2 + 2CO2 = 2Na2CO3 + O2 呼吸面具供氧原理 ——
Na2O2 + SO2 = Na2SO4 过氧化钠的强氧化性 ——

碳酸钠与碳酸氢钠

反应方程式 反应条件/现象 离子方程式
Na2CO3 + 2HCl = 2NaCl + H2O + CO2↑ 较快产生气体 CO32− + 2H+ = H2O + CO2↑
NaHCO3 + HCl = NaCl + H2O + CO2↑ 剧烈产生气体（比碳酸钠快） HCO3− + H+ = H2O + CO2↑
Na2CO3 + Ca(OH)2 = CaCO3 ↓ +2NaOH 白色沉淀 CO32− + Ca2+ = CaCO3↓
NaHCO3 + NaOH = Na2CO3 + H2O —— HCO3− + OH− = CO32− + H2O
$2NaHCO_3 \stackrel{\Delta}{=\!=\!=} Na_2CO_3 + H_2O + CO_2\uparrow$ 受热分解 ——
Na2CO3 + CO2 + H2O = 2NaHCO3 向碳酸钠溶液通入CO₂ CO32− + CO2 + H2O = 2HCO3−

1.2 铝及其化合物

单质铝

反应方程式 反应条件/现象 离子方程式
4Al + 3O2 = 2Al2O3 常温钝化/点燃剧烈 ——
2Al + 6HCl = 2AlCl3 + 3H2↑ 剧烈反应 2Al + 6H+ = 2Al3+ + 3H2↑
2Al + 2NaOH + 2H2O = 2NaAlO2 + 3H2↑ 铝与强碱反应（两性） 2Al + 2OH− + 2H2O = 2AlO2− + 3H2↑
$2Al + Fe_2O_3 \stackrel{高温}{=\!=\!=} Al_2O_3 + 2Fe$ 铝热反应，放出大量热 ——

氧化铝与氢氧化铝

反应方程式 反应条件/现象 离子方程式
Al2O3 + 6HCl = 2AlCl3 + 3H2O 两性氧化物 Al2O3 + 6H+ = 2Al3+ + 3H2O
Al2O3 + 2NaOH = 2NaAlO2 + H2O 两性氧化物 Al2O3 + 2OH− = 2AlO2− + H2O
Al(OH)3 + 3HCl = AlCl3 + 3H2O 两性氢氧化物 Al(OH)3 + 3H+ = Al3+ + 3H2O
Al(OH)3 + NaOH = NaAlO2 + 2H2O 两性氢氧化物 Al(OH)3 + OH− = AlO2− + 2H2O
$2Al(OH)_3 \stackrel{\Delta}{=\!=\!=} Al_2O_3 + 3H_2O$ 受热分解 ——
AlCl3 + 3NH3 ⋅ H2O = Al(OH)3 ↓ +3NH4Cl 实验室制氢氧化铝，白色胶状沉淀 Al3+ + 3NH3 ⋅ H2O = Al(OH)3 ↓ +3NH4+

铝三角转化

转化 离子方程式
Al3+ → Al(OH)3 Al3+ + 3OH− = Al(OH)3↓（加少量强碱/过量弱碱）
Al(OH)3 → Al3+ Al(OH)3 + 3H+ = Al3+ + 3H2O
Al3+ → AlO2− Al3+ + 4OH− = AlO2− + 2H2O（加过量强碱）
AlO2− → Al(OH)3 AlO2− + H+ + H2O = Al(OH)3↓（加少量强酸）
Al(OH)3 → AlO2− Al(OH)3 + OH− = AlO2− + 2H2O
AlO2− → Al3+ AlO2− + 4H+ = Al3+ + 2H2O（加过量强酸）

1.3 铁及其化合物

单质铁

反应方程式 反应条件/现象 离子方程式
$3Fe + 2O_2 \stackrel{点燃}{=\!=\!=} Fe_3O_4$ 火星四射，黑色固体 ——
$Fe + S \stackrel{\Delta}{=\!=\!=} FeS$ 黑色固体 ——
$2Fe + 3Cl_2 \stackrel{点燃}{=\!=\!=} 2FeCl_3$ 棕黄色烟 ——
Fe + H2SO4 = FeSO4 + H2↑ 稀硫酸，浅绿色溶液 Fe + 2H+ = Fe2+ + H2↑
Fe + 4HNO3(稀) = Fe(NO3)3 + NO ↑ +2H2O 足量稀硝酸，生成Fe³⁺ Fe + 4H+ + NO3− = Fe3+ + NO ↑ +2H2O
3Fe + 8HNO3(稀) = 3Fe(NO3)2 + 2NO ↑ +4H2O 铁过量，生成Fe²⁺ 3Fe + 8H+ + 2NO3− = 3Fe2+ + 2NO ↑ +4H2O
$3Fe + 4H_2O(g) \stackrel{高温}{=\!=\!=} Fe_3O_4 + 4H_2$ 铁与水蒸气反应 ——

铁的氧化物与氢氧化物

反应方程式 反应条件/现象 离子方程式
FeO + 2HCl = FeCl2 + H2O 黑色粉末溶解 FeO + 2H+ = Fe2+ + H2O
Fe2O3 + 6HCl = 2FeCl3 + 3H2O 红棕色粉末溶解，黄色溶液 Fe2O3 + 6H+ = 2Fe3+ + 3H2O
FeSO4 + 2NaOH = Fe(OH)2 ↓ +Na2SO4 白色沉淀→迅速变灰绿→最后变红褐 Fe2+ + 2OH− = Fe(OH)2↓
4Fe(OH)2 + O2 + 2H2O = 4Fe(OH)3 氢氧化亚铁被氧化 ——
FeCl3 + 3NaOH = Fe(OH)3 ↓ +3NaCl 红褐色沉淀 Fe3+ + 3OH− = Fe(OH)3↓

Fe²⁺与Fe³⁺的相互转化

转化 离子方程式
Fe2+ → Fe3+ 2Fe2+ + Cl2 = 2Fe3+ + 2Cl−
Fe2+ → Fe3+ 3Fe2+ + 4H+ + NO3− = 3Fe3+ + NO ↑ +2H2O（稀硝酸）
Fe3+ → Fe2+ 2Fe3+ + Fe = 3Fe2+
Fe3+ → Fe2+ 2Fe3+ + Cu = 2Fe2+ + Cu2+
Fe³⁺检验 Fe3+ + 3SCN− = Fe(SCN)3（溶液变血红色）

1.4 铜及其化合物

反应方程式 反应条件/现象 离子方程式
$2Cu + O_2 \stackrel{\Delta}{=\!=\!=} 2CuO$ 红色变黑色 ——
$Cu + Cl_2 \stackrel{点燃}{=\!=\!=} CuCl_2$ 棕黄色烟 ——
$Cu + 2H_2SO_4(浓) \stackrel{\Delta}{=\!=\!=} CuSO_4 + SO_2\uparrow + 2H_2O$ 浓硫酸，刺激性气味气体 $Cu + 4H^+ + SO_4^{2-} \stackrel{\Delta}{=\!=\!=} Cu^{2+} + SO_2\uparrow + 2H_2O$
Cu + 4HNO3(浓) = Cu(NO3)2 + 2NO2 ↑ +2H2O 浓硝酸，红棕色气体 Cu + 4H+ + 2NO3− = Cu2+ + 2NO2 ↑ +2H2O
3Cu + 8HNO3(稀) = 3Cu(NO3)2 + 2NO ↑ +4H2O 稀硝酸，无色气体，遇空气变红棕 3Cu + 8H+ + 2NO3− = 3Cu2+ + 2NO ↑ +4H2O

1.5 氯及其化合物

反应方程式 反应条件/现象 离子方程式
$Cu + Cl_2 \stackrel{点燃}{=\!=\!=} CuCl_2$ 棕黄色烟 ——
$2Fe + 3Cl_2 \stackrel{点燃}{=\!=\!=} 2FeCl_3$ 棕褐色烟 ——
$H_2 + Cl_2 \stackrel{点燃}{=\!=\!=} 2HCl$ 安静燃烧，苍白色火焰 ——
Cl2 + H2O ⇌ HCl + HClO 氯水浅黄绿色，具有漂白性 Cl2 + H2O ⇌ H+ + Cl− + HClO
Cl2 + 2NaOH = NaCl + NaClO + H2O 常温制漂白液 Cl2 + 2OH− = Cl− + ClO− + H2O
$3Cl_2 + 6NaOH \stackrel{\Delta}{=\!=\!=} 5NaCl + NaClO_3 + 3H_2O$ 热碱，生成氯酸钠 $3Cl_2 + 6OH^- \stackrel{\Delta}{=\!=\!=} 5Cl^- + ClO_3^- + 3H_2O$
2Cl2 + 2Ca(OH)2 = CaCl2 + Ca(ClO)2 + 2H2O 工业制漂白粉 ——
$2HClO \stackrel{光照}{=\!=\!=} 2HCl + O_2\uparrow$ 次氯酸见光分解 ——
$MnO_2 + 4HCl(浓) \stackrel{\Delta}{=\!=\!=} MnCl_2 + Cl_2\uparrow + 2H_2O$ 实验室制氯气 $MnO_2 + 4H^+ + 2Cl^- \stackrel{\Delta}{=\!=\!=} Mn^{2+} + Cl_2\uparrow + 2H_2O$

1.6 硫及其化合物

反应方程式 反应条件/现象 离子方程式
$Fe + S \stackrel{\Delta}{=\!=\!=} FeS$ 黑色固体 ——
$S + O_2 \stackrel{点燃}{=\!=\!=} SO_2$ 蓝紫色火焰（纯氧） ——
$2SO_2 + O_2 \underset{\Delta}{\stackrel{催化剂}{\rightleftharpoons}} 2SO_3$ 工业制硫酸第二步，可逆反应 ——
SO2 + H2O ⇌ H2SO3 可逆反应 ——
SO2 + 2NaOH = Na2SO3 + H2O 尾气处理 SO2 + 2OH− = SO32− + H2O
SO2 + Cl2 + 2H2O = H2SO4 + 2HCl 氯水与二氧化硫同时通入，漂白性消失 SO2 + Cl2 + 2H2O = 4H+ + SO42− + 2Cl−
$Cu + 2H_2SO_4(浓) \stackrel{\Delta}{=\!=\!=} CuSO_4 + SO_2\uparrow + 2H_2O$ 浓硫酸强氧化性 ——
$C + 2H_2SO_4(浓) \stackrel{\Delta}{=\!=\!=} CO_2\uparrow + 2SO_2\uparrow + 2H_2O$ 浓硫酸与非金属反应 ——
Na2SO3 + H2SO4(浓) = Na2SO4 + SO2 ↑ +H2O 实验室制SO₂ ——

1.7 氮及其化合物

反应方程式 反应条件/现象 离子方程式
$N_2 + 3H_2 \underset{高温高压}{\stackrel{催化剂}{\rightleftharpoons}} 2NH_3$ 工业合成氨，可逆反应 ——
$N_2 + O_2 \stackrel{放电}{=\!=\!=} 2NO$ 自然固氮 ——
2NO + O2 = 2NO2 无色气体变红棕色 ——
3NO2 + H2O = 2HNO3 + NO 工业制硝酸第三步 3NO2 + H2O = 2H+ + 2NO3− + NO
$4NH_3 + 5O_2 \underset{\Delta}{\stackrel{催化剂}{=\!=\!=}} 4NO + 6H_2O$ 氨的催化氧化，工业制硝酸基础 ——
NH3 + HCl = NH4Cl 白烟，检验氨气 ——
$NH_4Cl \stackrel{\Delta}{=\!=\!=} NH_3\uparrow + HCl\uparrow$ 铵盐受热分解 ——
$2NH_4Cl + Ca(OH)_2 \stackrel{\Delta}{=\!=\!=} CaCl_2 + 2NH_3\uparrow + 2H_2O$ 实验室制氨气 ——
Cu + 4HNO3(浓) = Cu(NO3)2 + 2NO2 ↑ +2H2O 浓硝酸 ——
3Cu + 8HNO3(稀) = 3Cu(NO3)2 + 2NO ↑ +4H2O 稀硝酸 ——

1.8 硅及其化合物

反应方程式 反应条件/现象 离子方程式
$Si + O_2 \stackrel{\Delta}{=\!=\!=} SiO_2$ —— ——
Si + 2NaOH + H2O = Na2SiO3 + 2H2↑ 硅与强碱反应 Si + 2OH− + H2O = SiO32− + 2H2↑
$SiO_2 + 2C \stackrel{高温}{=\!=\!=} Si + 2CO\uparrow$ 工业制粗硅 ——
SiO2 + 2NaOH = Na2SiO3 + H2O 碱液不能用玻璃塞 SiO2 + 2OH− = SiO32− + H2O
SiO2 + 4HF = SiF4 ↑ +2H2O 氢氟酸刻蚀玻璃 ——
Na2SiO3 + 2HCl = H2SiO3 ↓ +2NaCl 硅酸胶体（白色胶状） SiO32− + 2H+ = H2SiO3↓

板块二：有机化学方程式大全（按官能团分类）

2.1 烷烃

反应方程式 反应类型 反应条件
$CH_4 + Cl_2 \stackrel{光}{\to} CH_3Cl + HCl$ 取代反应 光照，逐步取代
$CH_3Cl + Cl_2 \stackrel{光}{\to} CH_2Cl_2 + HCl$ 取代反应 光照
$CH_2Cl_2 + Cl_2 \stackrel{光}{\to} CHCl_3 + HCl$ 取代反应 光照
$CHCl_3 + Cl_2 \stackrel{光}{\to} CCl_4 + HCl$ 取代反应 光照
$C_nH_{2n+2} + \frac{3n+1}{2}O_2 \stackrel{点燃}{\to} nCO_2 + (n+1)H_2O$ 氧化反应（燃烧） 点燃

2.2 烯烃与炔烃

反应方程式 反应类型 反应条件
CH2 = CH2 + Br2 → CH2BrCH2Br 加成反应 溴水/溴的四氯化碳溶液，褪色
$CH_2=CH_2 + H_2 \underset{\Delta}{\stackrel{催化剂}{\to}} CH_3CH_3$ 加成反应 催化剂、加热
CH2 = CH2 + HCl → CH3CH2Cl 加成反应 催化剂
$CH_2=CH_2 + H_2O \underset{加热加压}{\stackrel{催化剂}{\to}} CH_3CH_2OH$ 加成反应 工业制乙醇
$nCH_2=CH_2 \stackrel{催化剂}{\to} [-CH_2-CH_2-]_n$ 加聚反应 聚乙烯
CH ≡ CH + Br2 → CHBr = CHBr 加成反应 1:1加成
CH ≡ CH + 2Br2 → CHBr2CHBr2 加成反应 1:2加成

板块四：化学反应原理核心知识点与公式

4.1 反应热与盖斯定律

基本概念

  • 反应热（焓变）：ΔH = 生成物总焓 - 反应物总焓

  • 放热反应：ΔH < 0，反应物总能量 > 生成物总能量

  • 吸热反应：ΔH > 0，反应物总能量 < 生成物总能量

热化学方程式书写要点

  1. 注明各物质的聚集状态（s、l、g、aq）

  2. 化学计量数可以是整数，也可以是分数

  3. ΔH单位为kJ/mol，必须写正负号

  4. ΔH数值与化学计量数成正比

盖斯定律

内容：不管化学反应是一步完成或分几步完成，其反应热是相同的。即化学反应的反应热只与反应体系的始态和终态有关，而与反应的途径无关。

计算方法：目标方程式 = 已知方程式的线性组合，ΔH也做相应的代数运算。

示例： 已知： ① C(s) + O2(g) = CO2(g) ΔH₁ = -393.5 kJ/mol ② $CO(g) + \frac{1}{2}O_2(g) = CO_2(g)$ ΔH₂ = -283.0 kJ/mol 求：$C(s) + \frac{1}{2}O_2(g) = CO(g)$ 的ΔH 解：① - ② = 目标方程式 ΔH = ΔH₁ - ΔH₂ = -393.5 - (-283.0) = -110.5 kJ/mol

4.2 原电池与电解池

原电池（将化学能转化为电能）

项目 负极 正极
电极判断 较活泼金属 较不活泼金属（或石墨）
电子流向 流出电子 流入电子
反应类型 氧化反应 还原反应
离子移动 阴离子移向负极 阳离子移向正极

铜锌原电池电极反应式：

  • 负极（Zn）：Zn − 2e− = Zn2+（氧化）

  • 正极（Cu）：2H+ + 2e− = H2↑（还原）

  • 总反应：Zn + H2SO4 = ZnSO4 + H2↑

电解池（将电能转化为化学能）

项目 阳极 阴极
电极连接 接电源正极 接电源负极
反应类型 氧化反应 还原反应
离子移动 阴离子移向阳极 阳离子移向阴极

氯碱工业（电解饱和食盐水）：

  • 阳极（石墨）：2Cl− − 2e− = Cl2↑

  • 阴极（铁）：2H+ + 2e− = H2↑

  • 总反应：$2NaCl + 2H_2O \stackrel{电解}{=\!=\!=} 2NaOH + H_2\uparrow + Cl_2\uparrow$

电解精炼铜：

  • 阳极（粗铜）：Cu − 2e− = Cu2+

  • 阴极（纯铜）：Cu2+ + 2e− = Cu

  • 电解质：CuSO₄溶液

电镀：

  • 镀件作阴极，镀层金属作阳极，含镀层金属离子的溶液作电镀液

4.3 化学反应速率与化学平衡

化学反应速率

  • 定义：$v = \frac{\Delta c}{\Delta t}$，单位：mol/(L·s) 或 mol/(L·min)

  • 同一反应，用不同物质表示的速率之比 = 化学计量数之比

影响速率的因素

因素 影响规律
浓度 增大反应物浓度，反应速率加快
温度 升高温度，反应速率加快（每升高10℃，速率增大2~4倍）
压强 增大压强（缩小体积），反应速率加快（有气体参与的反应）
催化剂 加入催化剂，反应速率大幅加快（正逆速率同等程度改变）

化学平衡

  • 定义：正反应速率 = 逆反应速率，各组分浓度不再改变

  • 特征：逆、等、动、定、变

化学平衡常数 K

  • 对于反应 mA(g) + nB(g) ⇌ pC(g) + qD(g)

$K = \frac{[C]^p[D]^q}{[A]^m[B]^n}$

  • K只与温度有关，与浓度、压强无关

  • K越大，反应进行得越完全

平衡移动（勒夏特列原理）

如果改变影响平衡的一个条件（如浓度、压强、温度），平衡就向能够减弱这种改变的方向移动。

条件改变 平衡移动方向
增大反应物浓度 向正反应方向移动
升高温度 向吸热反应方向移动
增大压强 向气体体积减小的方向移动
加催化剂 不移动（同等程度改变正逆速率）

4.4 弱电解质的电离平衡

电离平衡常数 Kₐ

  • 弱酸 HA ⇌ H+ + A−：$K_a = \frac{[H^+][A^-]}{[HA]}$

  • Kₐ越大，酸性越强

  • Kₐ只与温度有关，温度越高，Kₐ越大

影响电离平衡的因素

  • 温度：升高温度，电离平衡正向移动（电离吸热）

  • 浓度：稀释，电离平衡正向移动（越稀越电离）

  • 同离子效应：加入相同离子，平衡逆向移动

4.5 水的电离与溶液pH

水的离子积 K_w

H2O ⇌ H+ + OH−

Kw = [H+][OH−]

  • 25℃时：Kw = 1 × 10−14

  • K_w只与温度有关，温度升高，K_w增大

pH计算

pH = −lg [H+]

  • 25℃时：

    • 酸性溶液：[H⁺] > [OH⁻]，pH < 7

    • 中性溶液：[H⁺] = [OH⁻]，pH = 7

    • 碱性溶液：[H⁺] < [OH⁻]，pH > 7

4.6 盐类的水解

实质

盐电离出的离子与水电离出的H⁺或OH⁻结合生成弱电解质，促进水的电离。

规律

有弱才水解，越弱越水解；谁强显谁性，同强显中性。

盐的类型 实例 是否水解 溶液酸碱性
强酸强碱盐 NaCl、KNO₃ 不水解 中性
强酸弱碱盐 NH₄Cl、FeCl₃ 弱碱阳离子水解 酸性
弱酸强碱盐 CH₃COONa、Na₂CO₃ 弱酸阴离子水解 碱性
弱酸弱碱盐 CH₃COONH₄ 双水解 取决于两者相对强弱

水解离子方程式书写

  • 一般用可逆号，不标↑↓（双水解完全的除外）

  • 多元弱酸根分步水解，以第一步为主

示例：

NH4+ + H2O ⇌ NH3 ⋅ H2O + H+

CH3COO− + H2O ⇌ CH3COOH + OH−

4.7 沉淀溶解平衡

溶度积 K_sp

  • 对于沉淀溶解平衡：AmBn(s) ⇌ mAn+(aq) + nBm−(aq)

Ksp = [An+]m ⋅ [Bm−]n

  • K_sp只与温度和物质本身性质有关

溶度积规则

Qc > Ksp：过饱和溶液，析出沉淀

Qc = Ksp：饱和溶液，达到平衡

Qc < Ksp：不饱和溶液，无沉淀析出

沉淀的转化

一般来说，溶解度小的沉淀容易转化为溶解度更小的沉淀。 如：AgCl（白色）→ AgBr（淡黄）→ AgI（黄色）→ Ag₂S（黑色）

板块五：高频易错点与陷阱

5.1 氧化还原反应配平易错点

易错点 正确理解
化合价判断错误 常见变价元素：Fe（+2/+3）、Cu（+1/+2）、S（-2/0/+4/+6）、N（-3/0/+2/+4/+5）
只配平原子，不配平电荷 离子方程式配平必须同时满足原子守恒和电荷守恒
部分氧化还原反应漏算 如Cu与稀硝酸反应，硝酸既表现氧化性又表现酸性（部分被还原，部分成盐）
歧化反应配平 同一元素既升价又降价，从生成物开始配平更方便

5.2 离子共存问题

不能共存的情况 举例
生成难溶物 Ba²⁺与SO₄²⁻、Ag⁺与Cl⁻、Ca²⁺与CO₃²⁻
生成气体 H⁺与CO₃²⁻、HCO₃⁻、SO₃²⁻；OH⁻与NH₄⁺
生成弱电解质 H⁺与OH⁻、CH₃COO⁻、F⁻；OH⁻与HCO₃⁻
发生氧化还原反应 Fe³⁺与I⁻、S²⁻；NO₃⁻(H⁺)与Fe²⁺、I⁻；MnO₄⁻与Fe²⁺、Cl⁻
发生双水解 Al³⁺与AlO₂⁻、CO₃²⁻、HCO₃⁻、S²⁻；Fe³⁺与HCO₃⁻、CO₃²⁻
发生络合反应 Fe³⁺与SCN⁻

隐含条件陷阱：

  • “无色透明溶液”：排除Cu²⁺（蓝）、Fe³⁺（黄）、Fe²⁺（浅绿）、MnO₄⁻（紫）

  • “pH=1”或”pH=13”：强酸性或强碱性，加入大量H⁺或OH⁻

  • “与Al反应放出H₂”：可能是酸性溶液（非硝酸），也可能是碱性溶液

5.3 原电池与电解池判断易错点

易错点 正确理解
原电池正负极判断 负极失电子、发生氧化反应；正极得电子、发生还原反应。不一定是活泼金属作负极（如Mg-Al-NaOH原电池，Al作负极）
电解池阴阳极判断 阳极接电源正极，失电子、氧化反应；阴极接电源负极，得电子、还原反应
离子移动方向 原电池：阴离子移向负极，阳离子移向正极；电解池：阴离子移向阳极，阳离子移向阴极
放电顺序 阳极：活性电极 > S²⁻ > I⁻ > Br⁻ > Cl⁻ > OH⁻ > 含氧酸根；阴极：Ag⁺ > Fe³⁺ > Cu²⁺ > H⁺ > Fe²⁺ > Zn²⁺

5.4 化学平衡易错点

易错点 正确理解
平衡移动与转化率的关系 平衡正向移动，反应物转化率不一定都增大。如：反应物只有一种，增大该反应物浓度（恒容），平衡正向移动，但该反应物转化率可能增大、不变或减小，取决于反应前后气体计量数变化
催化剂不影响平衡 催化剂同等程度改变正逆反应速率，平衡不移动，只改变达到平衡的时间
压强对平衡的影响 压强改变只对有气体参与且反应前后气体体积不等的平衡有影响；加入惰性气体（恒容），平衡不移动
K只与温度有关 浓度、压强改变，K不变；温度改变，K才变

5.5 电解质溶液易错点

易错点 正确理解
K_w与温度的关系 K_w只与温度有关，温度升高，水的电离程度增大，K_w增大。pH=7不一定是中性（如100℃时pH=6为中性）
酸式盐溶液酸碱性 NaHSO₄：只电离不水解，溶液呈酸性；NaHCO₃：水解 > 电离，溶液呈碱性；NaHSO₃：电离 > 水解，溶液呈酸性
盐类水解的程度 水解程度一般很小，书写水解方程式时用可逆号，不标↑↓（双水解完全的除外）
Ksp与溶解度的关系 Ksp小的溶解度不一定小。只有同类型难溶物（如AB型）才能直接用Ksp比较溶解度；不同类型需换算

5.6 有机化学易错点

易错点 正确理解
苯的溴代 vs 加成 苯与液溴在FeBr₃催化下发生取代反应；苯与H₂在催化剂下发生加成反应。条件不同，反应类型不同
醇的消去 vs 氧化 乙醇170℃浓硫酸消去生成乙烯；乙醇Cu/Ag催化加热氧化生成乙醛。条件不同，产物不同
酯的水解条件 酸性水解可逆，生成羧酸和醇；碱性水解完全，生成羧酸盐和醇
能使溴水褪色的物质 烯、炔（加成）；苯酚（取代）；醛（氧化）；苯、四氯化碳（萃取，物理变化）
能使酸性KMnO₄褪色的物质 烯、炔、苯的同系物、醇、酚、醛、葡萄糖、麦芽糖等（还原性物质）
