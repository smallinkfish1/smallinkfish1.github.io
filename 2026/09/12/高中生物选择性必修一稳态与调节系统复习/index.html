高中生物选择性必修一 稳态与调节 系统复习大全

发表于 2026-09-12 分类于 knowledge

高中生物选择性必修一 稳态与调节 系统复习大全

（适配新高考、选修一全考点、一轮二轮通用、高考答题规范版）

前言

本资料整合人体内环境与稳态、神经调节、体液调节、免疫调节、植物激素调节五大核心模块，覆盖全部高考考点、经典实验与高频易错点，语言严谨、条理清晰，可直接用于复习背诵与考前复盘。

一、章节知识点全景图

1.1 人体内环境与稳态

知识点 核心内容 高考要求
体液组成 细胞内液（约占 2/3）+ 细胞外液（约占 1/3，即内环境） 识记
内环境组成 血浆、组织液、淋巴液（脑脊液）三者相互转化关系 理解 + 应用
内环境成分判断 血浆蛋白（内环境）、血红蛋白（细胞内）、消化液（外界环境） 高频判断
理化性质 渗透压（主要由 Na⁺、Cl⁻维持）、酸碱度（pH 7.35~7.45）、温度（约 37℃） 理解
稳态概念 正常机体通过调节作用，使各个器官、系统协调活动，共同维持内环境的相对稳定状态 理解
稳态调节机制 神经 — 体液 — 免疫调节网络（主要调节机制） 识记
稳态意义 机体进行正常生命活动的必要条件 识记

1.2 神经调节

知识点 核心内容 高考要求
神经系统组成 中枢神经系统（脑 + 脊髓）+ 外周神经系统（脑神经 + 脊神经） 识记
神经调节基本方式 反射（条件反射 + 非条件反射） 理解
反射弧结构 感受器 → 传入神经 → 神经中枢 → 传出神经 → 效应器（传出神经末梢 + 它所支配的肌肉或腺体） 高频考点
静息电位 外正内负，由K⁺外流维持（协助扩散） 必考
动作电位 外负内正，由Na⁺内流形成（协助扩散） 必考
兴奋在神经纤维上传导 双向传导，以局部电流形式 理解
突触结构 突触前膜 + 突触间隙 + 突触后膜 高频考点
兴奋在突触处传递 单向传递（神经递质只存在于突触小泡中，只能由突触前膜释放，作用于突触后膜） 必考
神经递质 种类（兴奋性 / 抑制性）、释放方式（胞吐）、作用后被分解或回收 理解

1.3 体液调节

知识点 核心内容 高考要求
激素调节概念 由内分泌器官或细胞分泌的化学物质进行调节 识记
下丘脑 — 垂体 — 甲状腺轴 下丘脑分泌 TRH → 垂体分泌 TSH → 甲状腺分泌甲状腺激素 高频考点
分级调节 下丘脑调控垂体，垂体调控相应内分泌腺 理解
负反馈调节 甲状腺激素浓度升高，反过来抑制下丘脑和垂体分泌 TRH、TSH 必考
血糖平衡调节 胰岛素（降血糖，胰岛 B 细胞）+ 胰高血糖素（升血糖，胰岛 A 细胞），二者拮抗 高频考点
体温调节 寒冷环境：骨骼肌战栗、甲状腺激素 / 肾上腺素分泌增加；炎热环境：毛细血管舒张、汗腺分泌增加 理解
水盐平衡调节 细胞外液渗透压升高 → 下丘脑渗透压感受器 → 垂体释放抗利尿激素 → 肾小管集合管重吸收水增加 高频考点
神经调节与体液调节关系 不少内分泌腺直接或间接受中枢神经系统调节；内分泌腺分泌的激素也可以影响神经系统的发育和功能 辨析

1.4 免疫调节

知识点 核心内容 高考要求
免疫系统组成 免疫器官、免疫细胞、免疫活性物质 识记
第一道防线 皮肤、黏膜及其分泌物 识记
第二道防线 体液中的杀菌物质（如溶菌酶）和吞噬细胞 识记
第三道防线 特异性免疫（体液免疫 + 细胞免疫），后天获得 必考
体液免疫 B 细胞活化 → 浆细胞 → 产生抗体 → 与抗原特异性结合 高频考点
细胞免疫 细胞毒性 T 细胞活化 → 裂解靶细胞 高频考点
免疫失调 过敏反应（已免疫机体再次接受相同抗原）、自身免疫病（敌我不分）、免疫缺陷病 辨析
疫苗 相当于抗原，诱导机体产生记忆细胞和抗体 应用

1.5 植物激素调节

知识点 核心内容 高考要求
生长素的发现 达尔文 → 鲍森・詹森 → 拜尔 → 温特实验 识记
生长素产生部位 幼嫩的芽、叶和发育中的种子 识记
生长素运输 极性运输（形态学上端→形态学下端，主动运输）+ 横向运输（单侧光 / 重力引起） 高频考点
生长素作用两重性 低浓度促进生长，高浓度抑制生长，甚至杀死植物 必考
顶端优势 顶芽优先生长，侧芽受抑制（顶芽生长素向下运输积累在侧芽，侧芽对生长素敏感，被抑制） 高频考点
其他植物激素 赤霉素（促进细胞伸长、促进种子萌发）、细胞分裂素（促进细胞分裂）、脱落酸（抑制细胞分裂、促进叶和果实衰老脱落）、乙烯（促进果实成熟） 识记 + 辨析
植物生长调节剂 人工合成的对植物生长发育有调节作用的化学物质（如 NAA、2,4-D） 应用

二、核心概念与生理过程

2.1 内环境的理化性质

理化性质 数值 / 特点 维持机制
渗透压 约 770 kPa（37℃），相当于 0.9% NaCl 溶液 主要由 Na⁺、Cl⁻、血浆蛋白维持
酸碱度 pH 7.35~7.45 HCO₃⁻/H₂CO₃、HPO₄²⁻/H₂PO₄⁻等缓冲物质
温度 约 37℃ 体温调节机制维持

2.2 兴奋传导与传递比较

比较项目 神经纤维上的传导 突触处的传递
形式 局部电流（电信号） 电信号 → 化学信号 → 电信号
方向 双向 单向
速度 快 慢（突触延搁）
原因 兴奋部位与未兴奋部位形成电位差，可向两侧传导 神经递质只存在于突触前膜的突触小泡中，只能由突触前膜释放，作用于突触后膜

2.3 突触传递单向性的原因

  1. 神经递质只储存于突触前膜内侧的突触小泡中；

  2. 神经递质只能由突触前膜释放；

  3. 神经递质的受体只存在于突触后膜上；

  4. 因此兴奋只能从一个神经元的轴突传递到下一个神经元的细胞体或树突，不能反向。

2.4 反馈调节机制

  • 概念：在一个系统中，系统本身工作的效果，反过来又作为信息调节该系统的工作。

  • 正反馈：促进并加强最初发生的那个过程（如血液凝固、排尿反射、分娩）。

  • 负反馈：减弱最初发生的那个过程，使系统趋于稳定（如甲状腺激素分泌调节、血糖调节、体温调节）。

  • 意义：是生命系统中非常普遍的调节机制，对于机体维持稳态具有重要意义。

2.5 特异性免疫过程

体液免疫流程

  1. 感应阶段：抗原被抗原呈递细胞（如树突状细胞）摄取和处理，呈递给辅助性 T 细胞；

  2. 反应阶段：辅助性 T 细胞活化并分泌细胞因子；B 细胞接受抗原刺激，在细胞因子作用下活化、增殖、分化为浆细胞和记忆 B 细胞；

  3. 效应阶段：浆细胞产生抗体，抗体与抗原特异性结合，抑制病原体增殖或黏附人体细胞，形成沉淀等被吞噬细胞吞噬消化。

细胞免疫流程

  1. 感应阶段：靶细胞（被病原体感染的宿主细胞）表面的某些分子发生变化；细胞毒性 T 细胞识别变化的信号；

  2. 反应阶段：细胞毒性 T 细胞活化、增殖、分化为新的细胞毒性 T 细胞和记忆 T 细胞；

  3. 效应阶段：活化的细胞毒性 T 细胞识别并接触、裂解靶细胞，释放出病原体；

  4. 病原体被抗体结合或被吞噬细胞吞噬消化。

2.6 生长素作用的两重性

浓度 作用效果 实例
低浓度 促进生长、促进发芽、防止落花落果 植物向光性（背光侧生长素多，生长快）
高浓度 抑制生长、抑制发芽、疏花疏果 顶端优势（侧芽生长素浓度高，被抑制）、除草剂（高浓度 2,4-D 杀死双子叶杂草）

敏感度曲线：根 > 芽 > 茎（根对生长素最敏感）

三、教材经典实验与探究

3.1 生物体维持 pH 稳定的机制（血浆 pH 测定）

项目 内容
实验原理 细胞代谢会产生许多酸性物质，如碳酸等；人和动物的血浆中含有许多对酸碱度起缓冲作用的物质，如 H₂CO₃/NaHCO₃、NaH₂PO₄/Na₂HPO₄等
实验设计 对比实验：自来水 → 缓冲液 → 生物材料（肝匀浆、血浆等），分别滴加酸或碱，测 pH 变化
结论 自来水不具有缓冲能力，缓冲液和生物材料均具有缓冲能力，说明生物材料类似缓冲液
注意事项 每次滴加酸 / 碱后要摇匀；每换一种材料或试剂，都要将烧杯和滴管冲洗干净

3.2 反射弧的分析（以屈腿反射为例）

实验步骤 结论
刺激完整坐骨神经 — 腓肠肌标本 腓肠肌收缩，说明神经和肌肉都具有兴奋性
剪断传入神经，刺激外周段 效应器不收缩；刺激向中段，效应器收缩 → 传入神经受损，反射不能完成
剪断传出神经，刺激外周段 效应器收缩；刺激向中段，效应器不收缩 → 传出神经受损，反射不能完成
结论 反射需要完整的反射弧才能完成

3.3 探究生长素类似物促进插条生根的最适浓度

项目 内容
实验原理 生长素类似物具有与生长素相似的生理效应；适宜浓度促进插条生根，浓度过高抑制生根
预实验 正式实验前先做预实验，确定大致浓度范围，避免人力物力浪费
实验设计 设置一系列浓度梯度的生长素类似物溶液，处理生长状况相同的插条形态学下端
处理方法 浸泡法（低浓度，处理几小时至一天）、沾蘸法（高浓度，处理约 5 秒）
因变量 插条生根的数量（或平均长度）
无关变量 处理时间、温度、光照、插条的生长状况等，各组保持相同且适宜
结论 生长素类似物促进插条生根存在最适浓度；在最适浓度两侧，存在两种不同浓度，但促进效果相同

3.4 生长素的发现系列实验

科学家 实验过程 结论
达尔文 胚芽鞘受单侧光照射，向光弯曲；切去尖端或用锡箔罩住尖端，不弯曲；罩住尖端下部，仍弯曲 胚芽鞘的尖端受单侧光刺激后，向下面的伸长区传递了某种 “影响”，造成伸长区背光面比向光面生长快
鲍森・詹森 切去胚芽鞘尖端，不生长不弯曲；尖端和下部之间放琼脂片，仍弯曲生长 胚芽鞘尖端产生的影响可以透过琼脂片传递给下部
拜尔 切去胚芽鞘尖端，移至一侧，置于黑暗中，胚芽鞘向放置尖端的对侧弯曲生长 胚芽鞘的弯曲生长，是因为尖端产生的影响在其下部分布不均匀造成的
温特 接触过胚芽鞘尖端的琼脂块放在切去尖端的胚芽鞘一侧，胚芽鞘向对侧弯曲；未接触过尖端的琼脂块不弯曲 胚芽鞘的弯曲生长确实是由一种化学物质引起的，并将这种物质命名为生长素

四、高频易错点与易混淆概念辨析

4.1 兴奋传导 vs 传递：双向 vs 单向

易混点 正确理解
神经纤维上的传导方向 离体神经纤维上是双向传导；在机体内反射弧中，由于突触的存在，兴奋是单向传导的（从感受器到效应器）
突触处的传递方向 永远单向，只能从突触前神经元 → 突触后神经元
典型错误 “兴奋在反射弧中双向传导”—— 错，反射弧中有突触，只能单向

4.2 神经调节与体液调节的区别与联系

比较项目 神经调节 体液调节
作用途径 反射弧 体液运输
反应速度 迅速 较缓慢
作用范围 准确、比较局限 较广泛
作用时间 短暂 比较长
联系 ①不少内分泌腺直接或间接地受中枢神经系统的调节；②内分泌腺分泌的激素也可以影响神经系统的发育和功能（如甲状腺激素）；③动物体的各项生命活动常常同时受神经和体液的共同调节

4.3 第一道防线 vs 第二道防线

比较项目 第一道防线 第二道防线
组成 皮肤、黏膜及其分泌物 体液中的杀菌物质（如溶菌酶）和吞噬细胞
作用对象 多种病原体（非特异性） 多种病原体（非特异性）
特点 生来就有，不针对某一类特定病原体 生来就有，不针对某一类特定病原体
共同点 都属于非特异性免疫（先天性免疫）

易错提醒：溶菌酶杀菌若在口腔内进行，属于第一道防线；若在血浆中进行，属于第二道防线。

4.4 激素 vs 酶

比较项目 激素 酶
化学本质 蛋白质类、固醇类、氨基酸衍生物等 绝大多数是蛋白质，少数是 RNA
产生部位 内分泌腺或内分泌细胞 活细胞（所有活细胞）
作用 调节生命活动（传递信息） 催化化学反应（降低反应活化能）
作用后去向 一经靶细胞接受并起作用后就被灭活 催化反应前后性质不变，可重复利用
共同点 都需要与特定分子结合后才能起作用；都具有微量高效的特点

4.5 生长素 vs 赤霉素

比较项目 生长素 赤霉素
合成部位 幼嫩的芽、叶和发育中的种子 未成熟的种子、幼根和幼芽
主要作用 促进细胞伸长；促进插条生根；促进果实发育；两重性 促进细胞伸长，从而引起植株增高；促进种子萌发和开花；解除种子、块茎休眠
作用特点 具有两重性（低促高抑） 一般只表现促进作用，无明显两重性
