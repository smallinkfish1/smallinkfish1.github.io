关于网站和我

关于博客

本站基于 Hexo 静态博客框架 搭建（后面有时间可能考虑更换框架，如Astro等），依托 GitHub Pages 进行免费稳定部署，全程采用 Markdown 语法进行内容创作，搭配 Git 完成源码版本管理与云端备份，无服务器运维压力，访问稳定、轻量化、专注内容本身。 本博客定位为个人理科知识库 & 学习素材档案馆 & 编程技术分享 & 日记，主要用于长期整理、沉淀高中理科知识点、物理数学公式体系、解题模型、高频易错总结、作文素材积累等学习内容。摒弃娱乐化内容，专注系统化知识归档，打造属于自己的私有在线学习资料库。

为什么使用Hexo？

配置方便，上传方便，作为高中生可能没那么多时间来整理自己的博客，而Hexo这个博客框架配置文件简单易懂，修改方便，适合短时间内快速配置

网站实现功能清单

  • ✅ 全站响应式适配：完美适配电脑、手机端浏览
  • ✅ LaTeX 数学/物理公式实时渲染，支持复杂理科公式展示
  • ✅ 站内全文搜索，快速检索知识点与素材
  • ✅ 标签、分类体系归档，知识点结构化整理
  • ✅ 完整站点地图收录，适配搜索引擎抓取
  • ✅ 源码github仓库私有备份，文章永久留存不丢失（只要github还在这个地球上）
  • ✅ 极简阅读界面，无广告、无冗余干扰，专注学习复盘
  • 后面考虑更换主题
