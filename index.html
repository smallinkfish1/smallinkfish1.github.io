反应方程式 反应条件/现象 离子方程式

$2HClO \stackrel{光照}{=\!=\!=} 2HCl + O_2\uparrow$ 次氯酸见光分解 ——

反应方程式 反应条件/现象 离子方程式
$Fe + S \stackrel{\Delta}{=\!=\!=} FeS$ 黑色固体 ——
$S + O_2 \stackrel{点燃}{=\!=\!=} SO_2$ 蓝紫色火焰（纯氧） ——
$2SO_2 + O_2 \underset{\Delta}{\stackrel{催化剂}{\rightleftharpoons}} 2SO_3$ 工业制硫酸第二步，可逆反应 ——
SO2 + H2O ⇌ H2SO3 可逆反应 ——
SO2 + 2NaOH = Na2SO3 + H2O 尾气处理 SO2 + 2OH− = SO32− + H2O
SO2 + Cl2 + 2H2O = H2SO4 + 2HCl 氯水与二氧化硫同时通入，漂白性消失 SO2 + Cl2 + 2H2O = 4H+ + SO42− + 2Cl−
$Cu + 2H_2SO_4(浓) \stackrel{\Delta}{=\!=\!=} CuSO_4 + SO_2\uparrow + 2H_2O$ 浓硫酸强氧化性 ——
$C + 2H_2SO_4(浓) \stackrel{\Delta}{=\!=\!=} CO_2\uparrow + 2SO_2\uparrow + 2H_2O$ 浓硫酸与非金属反应 ——
Na2SO3 + H2SO4(浓) = Na2SO4 + SO2 ↑ +H2O 实验室制SO₂ ——

反应方程式 反应条件/现象 离子方程式

4.1 反应热与盖斯定律

基本概念

  • 反应热（焓变）：ΔH = 生成物总焓 - 反应物总焓

  • 放热反应：ΔH < 0，反应物总能量 > 生成物总能量

  • 吸热反应：ΔH > 0，反应物总能量 < 生成物总能量

热化学方程式书写要点

  1. 注明各物质的聚集状态（s、l、g、aq）

  2. 化学计量数可以是整数，也可以是分数

  3. ΔH单位为kJ/mol，必须写正负号

  4. ΔH数值与化学计量数成正比

盖斯定律

内容：不管化学反应是一步完成或分几步完成，其反应热是相同的。即化学反应的反应热只与反应体系的始态和终态有关，而与反应的途径无关。

计算方法：目标方程式 = 已知方程式的线性组合，ΔH也做相应的代数运算。

示例： 已知： ① C(s) + O2(g) = CO2(g) ΔH₁ = -393.5 kJ/mol ② $CO(g) + \frac{1}{2}O_2(g) = CO_2(g)$ ΔH₂ = -283.0 kJ/mol 求：$C(s) + \frac{1}{2}O_2(g) = CO(g)$ 的ΔH 解：① - ② = 目标方程式 ΔH = ΔH₁ - ΔH₂ = -393.5 - (-283.0) = -110.5 kJ/mol

  • 正极（Cu）：2H+ + 2e− = H2↑（还原）

  • 总反应：Zn + H2SO4 = ZnSO4 + H2↑

4.3 化学反应速率与化学平衡

化学反应速率

  • 定义：$v = \frac{\Delta c}{\Delta t}$，单位：mol/(L·s) 或 mol/(L·min)

  • 同一反应，用不同物质表示的速率之比 = 化学计量数之比

影响速率的因素

因素 影响规律
浓度 增大反应物浓度，反应速率加快
温度 升高温度，反应速率加快（每升高10℃，速率增大2~4倍）
压强 增大压强（缩小体积），反应速率加快（有气体参与的反应）
催化剂 加入催化剂，反应速率大幅加快（正逆速率同等程度改变）

化学平衡

  • 定义：正反应速率 = 逆反应速率，各组分浓度不再改变

  • 特征：逆、等、动、定、变

化学平衡常数 K

  • 对于反应 mA(g) + nB(g) ⇌ pC(g) + qD(g)

$K = \frac{[C]^p[D]^q}{[A]^m[B]^n}$

  • K只与温度有关，与浓度、压强无关

  • K越大，反应进行得越完全

平衡移动（勒夏特列原理）

如果改变影响平衡的一个条件（如浓度、压强、温度），平衡就向能够减弱这种改变的方向移动。

条件改变 平衡移动方向
增大反应物浓度 向正反应方向移动
升高温度 向吸热反应方向移动
增大压强 向气体体积减小的方向移动
加催化剂 不移动（同等程度改变正逆速率）

4.4 弱电解质的电离平衡

电离平衡常数 Kₐ

  • 弱酸 HA ⇌ H+ + A−：$K_a = \frac{[H^+][A^-]}{[HA]}$

  • Kₐ越大，酸性越强

  • Kₐ只与温度有关，温度越高，Kₐ越大

影响电离平衡的因素

  • 温度：升高温度，电离平衡正向移动（电离吸热）

  • 浓度：稀释，电离平衡正向移动（越稀越电离）

  • 同离子效应：加入相同离子，平衡逆向移动

4.5 水的电离与溶液pH

水的离子积 K_w

H2O ⇌ H+ + OH−

Kw = [H+][OH−]

  • 25℃时：Kw = 1 × 10−14

  • K_w只与温度有关，温度升高，K_w增大

pH计算

pH = −lg [H+]

  • 25℃时：

    • 酸性溶液：[H⁺] > [OH⁻]，pH < 7

    • 中性溶液：[H⁺] = [OH⁻]，pH = 7

    • 碱性溶液：[H⁺] < [OH⁻]，pH > 7

4.6 盐类的水解

实质

盐电离出的离子与水电离出的H⁺或OH⁻结合生成弱电解质，促进水的电离。

规律

有弱才水解，越弱越水解；谁强显谁性，同强显中性。

盐的类型 实例 是否水解 溶液酸碱性
强酸强碱盐 NaCl、KNO₃ 不水解 中性
强酸弱碱盐 NH₄Cl、FeCl₃ 弱碱阳离子水解 酸性
弱酸强碱盐 CH₃COONa、Na₂CO₃ 弱酸阴离子水解 碱性
弱酸弱碱盐 CH₃COONH₄ 双水解 取决于两者相对强弱

水解离子方程式书写

  • 一般用可逆号，不标↑↓（双水解完全的除外）

  • 多元弱酸根分步水解，以第一步为主

示例：

NH4+ + H2O ⇌ NH3 ⋅ H2O + H+

CH3COO− + H2O ⇌ CH3COOH + OH−

4.7 沉淀溶解平衡

溶度积 K_sp

  • 对于沉淀溶解平衡：AmBn(s) ⇌ mAn+(aq) + nBm−(aq)

Ksp = [An+]m ⋅ [Bm−]n

  • K_sp只与温度和物质本身性质有关

溶度积规则

Qc > Ksp：过饱和溶液，析出沉淀

Qc = Ksp：饱和溶液，达到平衡

Qc < Ksp：不饱和溶液，无沉淀析出

沉淀的转化

一般来说，溶解度小的沉淀容易转化为溶解度更小的沉淀。 如：AgCl（白色）→ AgBr（淡黄）→ AgI（黄色）→ Ag₂S（黑色）

四、高频易错点与避坑指南（90% 学生丢分点）

（一）静电场易错点

  1. 正负号代入误区 电势、电势能、电势差、电场力做功必须带正负号计算！ 很多同学只代数值、忽略符号，结果完全相反。 例：负电荷在高电势处，电势能反而小。

  2. 电场强度与电势无关 场强大≠电势高，场强为零≠电势为零，二者无必然联系。

  3. 电场线与等势面垂直绝对成立 任意电场中，电场线永远垂直等势面，移动电荷沿等势面运动，电场力一定不做功。

  4. 电容器两大状态混淆（最高频丢分）

    • 通电：U 不变，d 增大→E 减小

    • 断电：Q 不变，d 增大→E 不变（最容易记错的考点）

  5. 电容公式误区 $C=\dfrac{Q}{U}$ 是定义式，C 与 Q、U 无关，只由极板本身结构决定。

（二）恒定电流易错点

  1. 纯电阻 / 非纯电阻电路区分 电动机、充电器为非纯电阻电路：

    • 电功 W = UIt（总电能）

    • 电热 Q = I2Rt（仅发热）

    • W > Q，不能混用 $W=\dfrac{U^2}{R}t$

  2. 电源输出功率误区 外电阻等于内阻时，电源输出功率最大，但此时效率不是最高。

  3. 动态电路分析顺序错误 必须：总电阻→总电流→内电压→路端电压→支路变量，不可逆推。

（三）磁场易错点

  1. 洛伦兹力永不做功 无论粒子如何运动，洛伦兹力始终垂直速度，不改变速度大小、只改方向，无能量变化。

  2. 零速度电荷不受磁场力 只有运动电荷在磁场中受洛伦兹力，静止电荷、恒定电流之外的静止电荷不受力。

  3. 圆周运动周期与速度无关 $T=\dfrac{2\pi m}{qB}$，粒子速度大小改变，轨迹半径改变，但周期不变。

  4. 左手定则使用误区 负电荷运动时，四指指向速度反方向，很多学生直接用速度方向判断，受力方向完全错误。

  5. 几何关系漏解 磁场边界问题常存在双解（两种轨迹、两个圆心角），做题必须考虑多解情况，极易漏分。

  1. 矢量（E、B、F）必须答大小 + 方向，只写数值直接扣分

  2. 标量（电势、电势能、电压）必须注意正负含义

  3. 所有二级结论仅限对应模型，不可随意通用套用
